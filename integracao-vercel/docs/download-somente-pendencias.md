# Download local somente pendências

A opção "Baixar somente pendências", no painel, exporta um arquivo JSON no próprio aparelho. Não chama um serviço externo, não compartilha automaticamente, não grava no Supabase e não altera a fila. O arquivo de recuperação pré-existente é identificado como "Baixar cópia completa de recuperação"; ele não é o arquivo menor, tem finalidades distintas e não é enviado ao suporte por esta alteração.

O arquivo contém mudanças em pedidos ativos, com identificador, versão e estado. Para edição, guarda somente os valores novos **tipados** dos campos alterados e seus caminhos; para criação, somente campos novos permitidos; para remoção, a referência. Há lista positiva de UUIDs, estados de negócio reconhecidos, datas, booleanos e contadores de Metas, municípios/remessas/núcleos/processos, planos e calendário. Inclui subestruturas tipadas de conclusão, histórico de ações e checklist de Metas. Não inclui nomes/títulos, texto livre, objetos arbitrários, configurações, dados opacos, valores anteriores, snapshots, recibos, pedidos encerrados nem bytes de anexos. Para arquivos inclui somente referências/versões de formato conhecido. Campos, edições, itens legados e referências rejeitados são contabilizados no JSON. Identificadores e estados/horários de negócio continuam privados; o arquivo só é baixado localmente e o usuário decide se o compartilha.

Não serve como restauração automática. A cópia completa de recuperação continua disponível quando faltarem os arquivos, a base ou outros dados não incluídos. Não há migration, RPC novo, Storage ou permissão. Testes sintéticos tratam canários recursivos de credenciais/base64/fila encerrada e mantêm cobertura da exportação completa (somente seletores foram renomeados nas jornadas antigas).
